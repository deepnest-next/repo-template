# Contributing

The general guidelines of the deepnest-next organisation apply:
https://github.com/deepnest-next/.github/blob/main/CONTRIBUTING.md

## Contributor License Agreement

This project is dual-licensed (`AGPL-3.0-or-later` or commercial). Before CI runs on or we merge
your pull request, every committer must sign the [CLA v2.0](CLA.md) ([Deutsch](CLA-de.md)) by
commenting on the pull request:

```
I have read the deepnest Contributor License Agreement v2.0 and I hereby sign the CLA.
```

One signature covers all deepnest-next repositories. CI starts automatically after everyone has
signed.

## Licence headers

Start every source file with an SPDX header in the file's comment syntax:

```
SPDX-License-Identifier: AGPL-3.0-or-later OR LicenseRef-Deepnest-Commercial
```

Third-party code must keep its original licence and notice. Name it in the pull request.
